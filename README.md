# Expense-Tracking-System
🔍 Project Overview

This project is an Expense Tracking System designed to help users record, analyze, and visualize personal expenses in order to understand spending patterns and make informed financial decisions.

The project demonstrates an end-to-end data analytics workflow, including data ingestion, data cleaning, exploratory data analysis, and visualization.

🛠️ Tech Stack

Python

Pandas – data cleaning and transformation

NumPy – numerical operations

Matplotlib / Seaborn – data visualization

Pycharm

FastAPI

✨ Key Features

Add and manage expense records (date, category, amount, description)

Data cleaning and preprocessing of expense data

Category-wise and time-based expense analysis

Monthly and yearly expense summaries

Visualizations to identify spending trends and patterns

Insight generation to highlight major expense categories

📈 Insights Generated

Identification of top spending categories

Monthly expense trends and spending behavior

Comparison between essential and discretionary expenses

Data-driven insights to support better budgeting decisions
